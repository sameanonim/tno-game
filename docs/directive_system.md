# 🎯 DirectiveSystem: Система национальных директив и проектов развития

## 📌 Общий обзор
Система директив (**Directive System**) представляет собой реализацию деревьев национальных фокусов TNO. Она моделирует принятие судьбоносных государственных решений, реализацию масштабных реформ и политических проектов.

---

## 🏛️ Архитектурные компоненты

```
core/systems/
├── directive_manager.gd           # Серверная логика: очередь прогресса, старт, валидация
├── focus_stage_controller.gd      # Динамическая смена стадий древа (Multi-Tree stages)
core/resources/
└── directive_resource.gd          # Ресурс директивы: стоимость, AST-условия, награды
ui/components/
├── directive_tree_view.gd         # Главный UI-терминал древа фокусов
├── directive_tree_canvas_drawer.gd# Процедурная отрисовка ортогональных шин и [X] связей
├── directive_node_factory.gd      # Генерация интерактивных карточек, CRT-стиль, тултипы
└── directive_inspector_formatter.gd # Досье директивы, AST-требования, опкоды эффектов
```

## 🌳 Структура директивы (`DirectiveResource`)

Каждая директива описывается ресурсом со следующими ключевыми параметрами:
- **`id`** (`String`): Уникальный системный идентификатор (например, `KOM_morozov_plan`).
- **`title` / `description`**: Локализованные заголовок и брифинг.
- **`cost_initial_cap`** (`int`): Затраты очков действий кабинета министров.
- **`cost_initial_pc`** (`float`): Затраты политического капитала (PC).
- **`turns_to_complete`** (`int`): Требуемое количество ходов для реализации (обычно 4–10 недель).
- **`prerequisites` / `prerequisites_groups`**: Предшествующие директивы (логика AND / OR).
- **`mutually_exclusive`**: Взаимоисключающие проекты (выбор одной ветки блокирует альтернативную).
- **`available_ast`**: Абстрактное синтаксическое дерево (AST) условий доступности, оцениваемое через `ConditionEvaluator`.
- **`bypass_ast`**: Условия автоматического пропуска (Bypass), если цель достигнута внешними событиями.
- **`completion_rewards`**: Массив структурированных опкодов наград (`MOD_PC`, `MOD_STABILITY`, `MOD_MANPOWER`, `SET_FLAG`, `FIRE_EVENT`).

## 🖥️ Визуальный терминал (`DirectiveTreeView`)

Терминал директив отображает направленный ациклический граф (DAG) со следующими возможностями:
1. **Свободное панорамирование и зум (Pan & Zoom)**: Масштабирование колесом мыши с фокусом на курсоре, панорамирование средней или правой кнопкой мыши.
2. **Процедурные ортогональные шины**: Автоматическая трассировка Z-образных соединений между родительскими и дочерними узлами.
3. **Псевдографика и статус прогресса**:
   - `✓ [ ВЫПОЛНЕНО ]` (неоновый циан)
   - `[████░░] 4/6 ХОД` (янтарный люминофор)
   - `► [ ГОТОВО К ПУСКУ ]` (изумрудный зеленый)
   - `✖ [ ЗАБЛОКИРОВАНО ВЫБОРОМ ]` (красный)
4. **Тактический инспектор**: Правая панель с подробным аудитом условий обстановки, стоимости и прогнозируемых геополитических эффектов.
