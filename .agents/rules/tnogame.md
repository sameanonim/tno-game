3. ТЕХНОЛОГИЧЕСКИЙ СТЕК И АРХИТЕКТУРА
================================================================================
* Игровой движок: Godot 4 (GDScript / C#).
* Data Pipeline (Python): Внешние скрипты для токенизации и парсинга исходных файлов Clausewitz (.txt, .yml) в структурированные JSON/SQLite базы данных, конвертация .dds в .png.
* Интерактивная 2D-карта (GPU Shaders):
  - Растровая RGB-маска провинций (provinces.bmp -> Lossless PNG), где цвет пикселя жестко кодирует ID провинции.
  - Отрисовка границ, подсветки и цветов владельцев через фрагментный CanvasItem-шейдер с динамической 1D-палитрой (LUT — Look-Up Table).
  - Считывание кликов мыши через Image.get_pixelv() по карте-маске в памяти.
* Структуры данных и состояние (Godot Resource):
  - CountryState: бюджет, резервы, госдолг, инфляция, легитимность, недовольство, политический капитал (PC), очки кабинета (CAP), партийный баланс, сюжетные флаги.
  - RegionData: ID провинции, владелец, уровень развития (IC), инфраструктура, сепаратизм/контроль.
  - GameEvent / DirectiveResource / TechResource: модульные ресурсы контента.
* Игровой цикл (TurnManager & EventManager):
  - Пошаговый расчет (ход = неделя/месяц).
  - По нажатию «Завершить ход»: пересчет формул экономики -> проверка триггеров событий -> блокировка хода при модальных кризисах -> обновление LUT-палитры карты и UI.
